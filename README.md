# Quantum machine learning-based parameterisation for atmospheric boundary layer turbulence

This repository provides the code for developing, training, and evaluating data-driven hybrid quantum and classical atmospheric turbulence parameterisations based on large eddy simulation (LES) experiments. The models are compared with regard to performance, generalisation and interpretability properties. The hybrid quantum models, which are based on parameterised circuits implemented with Pennylane (Ville Bergholm et al. PennyLane: Automatic differentiation of hybrid quantum-classical computations. 2018. [arXiv:1811.04968](https://arxiv.org/abs/1811.04968)), show similar performance and generalisation properties to classical models of comparable size. The feature importances quantified through SHAPLEY values (Scott M Lundberg and Su-In Lee, A Unified Approach to Interpreting Model Predictions, [Advances in Neural Information Processing Systems 30 (NIPS 2017)](https://proceedings.neurips.cc/paper_files/paper/2017/hash/8a20a8621978632d76c43dfd28b67767-Abstract.html)) are more stable in the quantum models with respect to initialisation of the weights and variational parameters, outlining possible advantages in physical stability and generalisability.
The current release on zenodo can be found here:
[![DOI](https://zenodo.org/badge/127326041.svg)](https://zenodo.org/badge/latestdoi/127326041)


### Data
The coarse-grained LES data on which this work is based, and details about the high-resolution data can be found in the data repository:
[![DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.20326041.svg)](https://doi.org/10.5281/zenodo.20326041)
The data were generated with the PALM model:
Maronga, B., et al (2020): Overview of the PALM model system 6.0, [Geosci. Model Dev., 13, 1335–1372](https://doi.org/10.5194/gmd-13-1335-2020)
Maronga, B., Gryschka, M., Heinze, R., Hoffmann, F., Kanani-Sühring, F., Keck, M., Ketelsen, K., Letzel, M. O., Sühring, M., and Raasch, S. (2015): The Parallelized Large-Eddy Simulation Model (PALM) version 4.0 for atmospheric and oceanic flows: model formulation, recent developments, and future perspectives, [Geosci. Model Dev., 8, 1539-1637](https://doi.org/10.5194/gmd-8-2515-2015)


## Repository contents
| Folder | Contents |
| ------ | -------- |
| `notebooks/` | Jupyter notebooks for data processing, model training, and figure generation (see below) |
| `scripts/` | Standalone Python scripts (see below) |
| `libs/` | Python modules used by scripts and notebooks
| `results/` | Generated output data (see below) |
| `figures/` | Figures (ignored by git, generated by notebooks) |

### Notebooks `notebooks/`)
| Notebook | Purpose |
| -------- | ------- |
| `coarsegraining.ipynb` | Coarse graining of the high-resolution data, including calculation of the subgrid-scale flux correction |
| `LES_data_figures.ipynb` | Figures 1 and 2 (with `Smagorinsky.ipynb`) |
| `preprocessing.ipynb` | Data preprocessing |
| `training_classical_nn.ipynb` | Classical NN training |
| `performance_eval.ipynb` | Figure 3 |
| `generalisation.ipynb` | Figure 4 |
| `shapley_values.ipynb` | Figure 5 |
| `qnn_hyperparams.ipynb` | Appendix |

### Scripts `scripts/`)
- `coarsegraining.py`: coarse graining of the high-resolution data
- `shap_sweep.py`: SHAP values calculation for all QNN
- `submit_shap_sweep`: jobscript for slurm (adjust to own parameters)
- `train_sweep.py`: QNN model training
- `submit_train_sweep`: jobscript for training
- `generalisation_profiles.py`: calculation of QNN performance profiles on unseem LES
- `submit_gen_profiles`: jobscript for profiles
- 
### Libs `libs/`)
- `dataloading.py`: loading and preprocessing data
- `PALMruns_overview.txt`: table of the LES experiments with prescribed parameters and save names
- `circuits.py`: object for PQCs with various architectures
- `qnn_models.py`: QNN model evaluation and training functions
- `helpers.py`: helper functions for plotting
- `notebookstyle_aps.mplstyle`: standard APS-like style for figures
  
### Results `results/`)
All contents are generated by the notebooks and scripts; the folders are committed as placeholders.
| Path | Contents |
| ---- | -------- |
| `results/QNN_results/` | Performance and output data of the QNN |
| `results/cl_results/` | Performance and output data of the classical NN |
| `results/cl_models/` | Saved classical NN model files |
| `results/abl_heights/` | Data for altitude of the boundary layer top, used to normalise height coordinate |
| `results/Smagorinsky*.txt` | Predictions from applying the Smagorinsky closure to the coarse data |


## Dependencies

The environement to run the codes and create a kernel for the notebooks can be created as:
```
conda env create --name my_env --file env.yml
conda activate my_env
```
In case the environment file ```env.yml``` is not working (most likely because some of the dependencies are not available anymore), we suggest creating the environment with the following key dependencies:
```
conda create -n my_env python=3.11 numpy matplotlib scipy pandas xarray scikit-learn pennylane jax keras
```

Install anaconda ipykernel (if needed) and create a new kernel for Jupyter Notebook:

```
conda install -c anaconda ipykernel
python -m ipykernel install --user --name=my_env
```
